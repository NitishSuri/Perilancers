# Perilancers

Marketing website for Perilancers, a two-person freelance tech studio.
Built with Next.js (App Router), TypeScript, Tailwind CSS v4, Framer Motion, and Resend.

## Editing content

All copy (services, FAQs, team, pricing, contact text, links) lives in **`lib/content.ts`**.
Search the project for `YOUR-` to find every placeholder that still needs a real value:

| Placeholder | Where |
| --- | --- |
| `https://YOUR-DOMAIN.com` | `site.url`: canonical URL, sitemap, Open Graph |
| `YOUR-BUSINESS-EMAIL@YOUR-DOMAIN.com` | `site.email` |
| `YOUR-WHATSAPP-NUMBER-WITH-COUNTRY-CODE` | `whatsappNumber`, digits only, e.g. `15551234567` |
| `YOUR-COMPANY-PAGE`, `YOUR-*-PROFILE` | LinkedIn URLs |

Other switches:

- **Testimonials:** add real reviews to `testimonials`, then set `SHOW_TESTIMONIALS = true`.
- **Team photos:** put images in `public/team/` and set `photo: "/team/khushi.jpg"` on a team member. Initials are shown until then.
- **Analytics:** set `NEXT_PUBLIC_GA_ID` (GA4) and Google Analytics loads automatically. Vercel Analytics is an alternative; see the comment at the top of `app/layout.tsx`.
- **Search Console / Bing:** paste verification codes into `site.verification` in `lib/content.ts`.

## SEO, AEO & marketing built in

| URL | What it is |
| --- | --- |
| `/robots.txt` | Generated by `app/robots.ts`. Allows search engines and AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, and more). |
| `/sitemap.xml` | Generated by `app/sitemap.ts`. Includes every service page automatically. |
| `/llms.txt` | Plain-language summary of the studio for AI assistants (llmstxt.org), generated from `lib/content.ts`. |
| `/services/[slug]` | One page per service, each with its own title, description, share image, FAQ, and structured data. |
| `/manifest.webmanifest` | Web app manifest. |

Structured data (JSON-LD): Organization + ProfessionalService, WebSite, WebPage, FAQPage, Service, and BreadcrumbList.
Contact form emails include the visitor's UTM source/medium/campaign, referrer, and landing page.

## Run locally

Requires Node.js 20.9+.

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev                  # http://localhost:3000
```

Other scripts: `npm run build`, `npm start`, `npm run lint`, `npm run typecheck`.

## Set up Resend (contact form email)

1. Create an account at [resend.com](https://resend.com).
2. **API key:** Dashboard → API Keys → Create. Copy it into `RESEND_API_KEY`.
3. **Recipient:** set `CONTACT_TO_EMAIL` to the inbox that should receive enquiries (comma-separate multiple addresses).
4. **Quick test:** with no `CONTACT_FROM_EMAIL`, emails are sent from `onboarding@resend.dev`. That sender only delivers to the email you signed up to Resend with.
5. **Production:** Dashboard → Domains → Add your domain, add the DNS records Resend shows you (SPF/DKIM), wait for "Verified", then set
   `CONTACT_FROM_EMAIL="Perilancers Website <hello@your-domain.com>"`.

The visitor's email is set as `reply-to`, so you can reply directly from your inbox.
If the keys are missing, the form shows a friendly message pointing people to your email address.

## Deploy to Vercel

1. Push this repository to GitHub.
2. In [Vercel](https://vercel.com/new), import the repository. The framework preset (Next.js) is detected automatically; no build settings need changing.
3. Under **Settings → Environment Variables**, add `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, and `CONTACT_FROM_EMAIL` for Production (and Preview if you want the form to work there).
4. Deploy.

### Custom domain

1. Vercel project → **Settings → Domains** → add `your-domain.com` and `www.your-domain.com`.
2. At your domain registrar, add the DNS records Vercel shows (typically an `A` record for the apex and a `CNAME` for `www`), or point your nameservers to Vercel.
3. Choose which one is primary (e.g. apex) and redirect the other to it.
4. Make sure `site.url` in `lib/content.ts` matches the primary domain exactly, then redeploy.
5. Submit `https://your-domain.com/sitemap.xml` in Google Search Console.

## Project structure

```
app/
  actions/contact.ts   Server Action: validates and sends enquiries via Resend
  privacy/page.tsx     Privacy Policy
  layout.tsx           Fonts, metadata, JSON-LD, navbar/footer, analytics slot
  page.tsx             Landing page (section order)
  globals.css          Tailwind theme (colors, fonts) and global styles
  opengraph-image.tsx  Generated social share image
  icon.svg, apple-icon.tsx, sitemap.ts, robots.ts, not-found.tsx
components/            One component per section, plus ui/ primitives
lib/
  content.ts           ← all editable copy
  validation.ts        Contact form rules shared by browser and server
  utils.ts
```
